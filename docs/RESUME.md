# 简历表述建议

以下表述以“已实现 MVP”为边界，避免把规划中的 F8/F9 说成已完成能力。

- 独立开发中文地理文本空间推理 Agent 平台，使用 LangGraph 编排“结构化解析—POI 检索—证据融合—三态决策—S2 空间化”工作流，支持 `RESOLVED/COARSE/ABSTAIN` 可审计输出。
- 设计受约束 LLM 工具边界：LLM 仅用于地点线索与空间关系提取，坐标和决策由确定性检索/策略节点控制，并提供规则回退与运行轨迹。
- 接入高德 POI 服务，完成 GCJ-02 到 WGS84 的服务端坐标统一；基于 MapLibre 和 S2 网格实现候选、误差范围与空间结果可视化。
- 构建自适应 S2 v0.2 原型，以语义不确定性、几何不确定性和关系证据驱动网格层级及覆盖范围；规划基于校准置信度和概率覆盖的后续优化。

面试中可展示三类输入：唯一实体、关系推断、信息不足拒答；同时说明“当前分数是可解释启发式，下一步将用标注集完成校准和评测”，这会比泛泛强调大模型更可信。
